# 돼지공주나라 서버 버전 (시제품 v2)

기존 Apps Script 앱과는 별개인 시험용 서버입니다. 기존 데이터에 영향을 주지 않습니다.

## 화면 구성
교사와 학생이 같은 배너 화면을 봅니다. 배너마다 **교사 모드** 버튼이 있고, 권한이 있는 사람에게만 보입니다.

| 배너 | 교사 모드에서 할 수 있는 일 | 누가 쓰나 |
|---|---|---|
| 💖 내 지갑 | 행복 지급/차감, 학생 등록, 직업 지정, 비밀번호 초기화 | 선생님 |
| 🛒 상점 | 상품 추가, 재고 새로 넣기(팔린 수 초기화), 삭제 | 선생님, 상점관리 학생 |
| 📒 내역·정산 | 월세·세금·벌금 징수, 국고 확인 | 선생님, 국세청장 학생 |
| 📒 내역·정산 | 월급 지급(소득세 10% 원천징수) | 선생님만 |

선생님은 위쪽 "학생 화면 미리보기"에서 학생을 골라 그 학생이 보는 화면 그대로 확인할 수 있습니다.

## 정산 규칙 (시험용으로 정한 것)
- 월급: 금액의 10%를 소득세로 떼어 국고로 보내고, 나머지를 지급합니다. 빚이 있으면 지급액으로 자동 상환됩니다.
- 월세·세금·벌금: 잔액이 부족해도 빚(마이너스)으로 처리하고 전액 국고로 갑니다. 월세 기본값은 30입니다.
- 구매는 잔액 부족 시 불가입니다.

## 1. Firebase 준비
1. Firebase 콘솔에서 프로젝트를 만들고 Firestore Database를 만듭니다.
2. 프로젝트 설정 → 서비스 계정 → 새 비공개 키 생성으로 JSON 파일을 받습니다. (GitHub에 올리지 마세요.)

## 2. GitHub와 Render
1. 이 폴더 전체를 새 저장소에 올립니다.
2. Render: New → Web Service → 저장소 연결, Build `npm install`, Start `npm start`
3. 환경변수 3개: `FIREBASE_SERVICE_ACCOUNT`(JSON 내용 전체), `TEACHER_PASSWORD`, `TOKEN_SECRET`(긴 임의 문자열)

## 3. 시험 순서
1. 선생님 탭으로 로그인 → 💖 내 지갑 → 교사 모드 → 학생 이름 등록
2. 같은 곳에서 행복 지급, 상점 배너에서 상품 추가
3. 📒 내역·정산 → 교사 모드 → 학생 선택 후 월급/월세 적용, 결과표와 국고 확인
4. 위쪽 "학생 화면 미리보기"로 학생 화면의 잔액·내역 확인
5. 직업 지정(상점관리/국세청장) 후 그 학생 번호로 로그인하면 해당 배너에만 교사 모드 버튼이 나타납니다.

## 참고
- 로그인은 시험 단계라 번호+비밀번호 방식입니다. 이후 구글 로그인으로 바꿀 예정입니다.
- Render 무료 서버는 한동안 접속이 없으면 잠들어 첫 접속이 느립니다. `/ping`을 주기적으로 호출하면 완화됩니다.
