# 돼지공주나라 서버 버전 (v3 · 3단계)

기존 Apps Script 앱과는 별개인 서버 버전입니다. 기존 데이터에는 영향을 주지 않습니다.

## 지금 들어 있는 것
서류철 + 포스트잇 탭 디자인, 종이 넘김 효과, 그리고 아래 배너의 **기존 규칙 그대로** 기능:

| 배너 | 내용 | 교사 모드 |
|---|---|---|
| 기본정보 | 행복·신용등급·수학등급(스스로 입력)·실수령 월급·월세·내 자리, 최근 내역, 비밀번호 변경 | 학생 관리(직업·수학·자리·비번 초기화), 월급 지급, 행복·신용 조정, 학생 등록, 국고, 설정 |
| 상점 | 세금(월세/전기세/건강보험료)·간식·쿠폰·공동구매 | 상품 추가/수정/숨김/삭제, 재고 새로 채우기, 세금 납부 현황, 공동구매 관리, 국고 |
| 은행 | 예금 1주·2주·1달(카드 3줄 설명, 신용등급별 이자율. 1주·2주 이자율은 임시값이니 교사 모드에서 맞춰 주세요), 중도해지(이자 없음), 내 예금 | 이자율 정하기, 만기 지급(이자는 국고에서), 해지 — 은행관리 직업도 가능 |
| 직업소 | 직업 목록, 지원 가능 여부(신용·수학 등급), 정원 | 직업 배정(등급 맞는 학생 자동 채우기), 모든 직업 비우기 |
| 우리반 보드 | padlet 카드 형식, 좌측 상단 + 버튼으로 글쓰기. 글(1000자)·사진(최대 5장, 화면에서 자동으로 줄임)·링크·댓글(300자)·추천(다시 누르면 취소). 내 글만 고치기/지우기 | 보드 만들기·이름/설명 수정·숨기기·댓글/추천 끄기·삭제, 선생님 이름으로 글쓰기, 글·댓글 숨기기 |
| 직업 활동 | 내 직업의 매일/주기적 할 일(없으면 '없음'), 직업별 도구: 경찰 벌금(지각 15·욕설/기타 직접 입력, 교사 승인 후 부과), 아르바이트 한 일 보고→수당 승인 요청, 국토교통부 자리 관리, 통계청 제출 체크, 국세청장 현황판·지출 신청, 신용등급 평가원 컷 조정 | 승인 탭에서 모아서 처리, 기타 탭에서 직업 편집·자리 확인·과제 즉시 체크 |

교사 모드를 켜면 해당 배너가 교사 화면으로 덮여요(맨 앞 '승인', 맨 뒤 '기타' 탭). 교사 모드 버튼은 권한이 있는 사람에게만 보입니다. 선생님은 전부, 학생은 직업의 권한(상점관리·국고관리 등)에 따라 해당 배너 일부만.
선생님은 위쪽 선택 칸에서 학생을 골라 그 학생이 보는 화면 그대로 미리 볼 수 있어요 (미리보기에서는 구매·참여가 막혀 있어요).

## 기존 앱과 같은 규칙
- 모든 돈의 움직임은 `ledger`(거래 원장)에 쌓이고, `students.balance`는 빠른 요약입니다. 같은 거래번호는 두 번 처리되지 않습니다.
- 상점에서 나간 돈은 전액 국고(`treasury`)로. 세금은 월세/전기세/건강보험료로 나눠 기록, 간식·쿠폰은 상점수입.
- 세금은 빚이 되어도 납부 가능(설정 `빚허용`), 간식·쿠폰은 빚이면 구매 금지(설정 `빚이면구매금지`).
- 세금 주기는 매달 16일에 새로 시작(설정 `세금초기화일`). 1인 구매 한도는 하루 기준(한국 시간 0시에 새로 시작).
- 재고 새로 채우기는 판매 기록을 지우지 않고 기준선만 옮깁니다.
- 월급: 직업 월급 − 소득세(10%) → 소득세는 국고로, 국고 재원 직업은 월급이 국고에서 나갑니다.
- 신용점수: 시작 15점 + 제출기록 합계, 등급 기준 24/18/12/6. 수학 등급 기준 90/80/70/60.
- 월세는 자리를 산 학생(자리 납부 체크)에게는 보이지 않습니다.
- 공동구매: 최소 300, 참여·취소(진행 중일 때), 완료 시 전액 국고, 목표 취소 시 전원 환불.

## 처음 쓰는 순서
1. 선생님으로 로그인 → 기본정보 → 교사 모드 → **학생 등록** (줄 순서가 번호, 처음 비밀번호 1111)
2. 학생 관리에서 직업·자리 지정 → 월급 지급
3. 상점 → 교사 모드에서 상품 확인/수정
처음 접속하면 직업 16개와 상점 상품 10개가 기존 앱과 같은 값으로 자동 생성됩니다.

## 설치 (이미 하셨다면 건너뛰세요)
1. Firebase: Firestore Database 생성 → 서비스 계정 비공개 키(JSON) 받기 (GitHub에 올리지 마세요)
2. Render: New → Web Service → 저장소 연결, Build `npm install`, Start `npm start`
3. 환경변수: `FIREBASE_SERVICE_ACCOUNT`(JSON 전체), `TEACHER_PASSWORD`, `TOKEN_SECRET`

## 기존 앱 데이터 가져오기
1. 기존 Apps Script 프로젝트에 `tools/내보내기.gs` 내용을 새 파일로 붙여넣고 `내보내기_서버버전` 실행 (읽기만 해요)
2. 드라이브에 생긴 `돼지공주나라_내보내기.json` 내려받기
3. 서버 버전 → 선생님 로그인 → 기본정보 → 교사 모드 → **데이터 가져오기** → 파일 선택 → 미리보기 → 가져오기
- 가져오는 것: 학생(이름·직업·수학·자리), 잔액(이월 1줄), 국고 잔액, 신용 기록, 직업, 상점(남은 재고·이번 달 납부·오늘 구매 수), 이자율, 진행 중 예금, 진행 중 공동구매, 설정, 보드 글·댓글·추천
- 안 가져오는 것: 거래원장, 보드 사진, 비밀번호(모두 1111)

## 보드 사진
사진은 Firebase Storage(유료 플랜) 대신 Firestore에 줄인 JPEG(긴 변 1000px, 약 100~300KB)로 글과 따로 저장합니다. 무료 한도(저장 1GiB)로 수천 장까지 충분합니다. 설정에서 글당 사진 수·댓글 수를 바꿀 수 있어요.

## 참고
- 이전 시제품에서 만든 학생·상품 데이터는 새 구조와 달라 화면에 나오지 않습니다 (필요하면 Firebase 콘솔에서 `students`, `items`, `meta` 컬렉션을 지우고 다시 등록하세요. 특히 `students`는 지우고 다시 등록하는 것을 권합니다).
- 로그인은 번호+비밀번호 방식입니다 (구글 로그인은 나중에).
- Render 무료 서버는 접속이 없으면 잠들어 첫 접속이 느립니다. `/ping`을 주기적으로 호출하면 완화됩니다.
