# 돼지공주나라 서버 버전 (v3 · 3단계)

기존 Apps Script 앱과는 별개인 서버 버전입니다. 기존 데이터에는 영향을 주지 않습니다.

## 지금 들어 있는 것
서류철 + 포스트잇 탭 디자인, 종이 넘김 효과, 그리고 아래 배너의 **기존 규칙 그대로** 기능:

| 배너 | 내용 | 교사 모드 |
|---|---|---|
| 기본정보 | 행복·신용등급·수학등급(스스로 입력)·실수령 월급·월세·내 자리, 최근 내역, 비밀번호 변경 | 학생 관리(직업·수학·자리·비번 초기화), 월급 지급, 행복·신용 조정, 학생 등록, 국고, 설정 |
| 상점 | 세금(월세/전기세/건강보험료)·간식·쿠폰·공동구매 | 상품 추가/수정/숨김/삭제, 재고 새로 채우기, 세금 납부 현황, 공동구매 관리, 국고 |
| 은행 | 예금 1주·2주·1달(카드 3줄 설명, 신용등급별 이자율. 1주·2주 이자율은 임시값이니 교사 모드에서 맞춰 주세요), 중도해지(이자 없음), 내 예금 | 이자율 정하기, 만기 지급(이자는 국고에서), 해지 — 은행관리 직업도 가능 |
| 직업소 | 직업 목록, 지원 가능 여부(신용·수학 등급), 정원 | 직업 배정(등급 맞는 학생 자동 채우기), 모든 직업 비우기 |
| 우리반 보드 | padlet 카드 형식, 좌측 상단 + 버튼으로 글쓰기. 글(1000자)·사진(최대 6장, 화면에서 자동으로 줄임)·파일(md·pdf·txt, 최대 3개, 한 개에 700KB까지)·링크·댓글(300자)·추천(다시 누르면 취소). 내 글만 고치기/지우기 | 보드 만들기·이름/설명 수정·숨기기·댓글/추천 끄기·삭제, 선생님 이름으로 글쓰기, 글·댓글 숨기기 |
| 직업 활동 | 내 직업의 매일/주기적 할 일(없으면 '없음'), 직업별 도구: 경찰 벌금(지각 15·욕설/기타 직접 입력, 교사 승인 후 부과), 아르바이트 한 일 보고→수당 승인 요청, 국토교통부 자리 관리, 통계청 제출 체크, 국세청장 현황판·지출 신청, 신용등급 평가원 컷 조정 | 승인 탭에서 모아서 처리, 기타 탭에서 직업 편집·자리 확인·과제 즉시 체크 |

교사 모드를 켜면 해당 배너가 교사 화면으로 덮여요(맨 앞 '승인', 맨 뒤 '기타' 탭). 교사 모드 버튼은 권한이 있는 사람에게만 보입니다. 선생님은 전부, 학생은 직업의 권한(상점관리·국고관리 등)에 따라 해당 배너 일부만.
선생님은 위쪽 선택 칸에서 학생을 골라 그 학생이 보는 화면 그대로 미리 볼 수 있어요 (미리보기에서는 구매·참여가 막혀 있어요).

## 기존 앱과 같은 규칙
- 모든 돈의 움직임은 `ledger`(거래 원장)에 쌓이고, `students.balance`는 빠른 요약입니다. 같은 거래번호는 두 번 처리되지 않습니다.
- 상점에서 나간 돈은 전액 국고(`treasury`)로. 세금은 월세/전기세/건강보험료로 나눠 기록, 간식·쿠폰은 상점수입.
- 세금은 빚이 되어도 납부 가능(설정 `빚허용`), 간식·쿠폰은 빚이면 구매 금지(설정 `빚이면구매금지`).
- 세금 주기는 매달 16일에 새로 시작(설정 `세금초기화일`). 1인 구매 한도는 하루 기준(한국 시간 0시에 새로 시작).
- 재고 새로 채우기는 판매 기록을 지우지 않고 기준선만 옮깁니다.
- 월급: 직업 월급 − 소득세(10%) → 소득세는 국고로, 국고 재원 직업은 월급이 국고에서 나갑니다.
- 신용점수: 시작 15점 + 제출기록 합계, 등급 기준 24/18/12/6. 수학 등급 기준 90/80/70/60.
- 월세는 자리를 산 학생(자리 납부 체크)에게는 보이지 않습니다.
- 공동구매: 최소 300, 참여·취소(진행 중일 때), 완료 시 전액 국고, 목표 취소 시 전원 환불.

## 처음 쓰는 순서
1. 선생님으로 로그인 → 기본정보 → 교사 모드 → **학생 등록** (줄 순서가 번호, 처음 비밀번호 1111)
2. 학생 관리에서 직업·자리 지정 → 월급 지급
3. 상점 → 교사 모드에서 상품 확인/수정
처음 접속하면 직업 16개와 상점 상품 10개가 기존 앱과 같은 값으로 자동 생성됩니다.

## 설치 (이미 하셨다면 건너뛰세요)
1. Firebase: Firestore Database 생성 → 서비스 계정 비공개 키(JSON) 받기 (GitHub에 올리지 마세요)
2. Render: New → Web Service → 저장소 연결, Build `npm install`, Start `npm start`
3. 환경변수: `FIREBASE_SERVICE_ACCOUNT`(JSON 전체), `TEACHER_PASSWORD`, `TOKEN_SECRET`

## 기존 앱 데이터 가져오기
1. 기존 Apps Script 프로젝트에 `tools/내보내기.gs` 내용을 새 파일로 붙여넣고 `내보내기_서버버전` 실행 (읽기만 해요)
2. 드라이브에 생긴 `돼지공주나라_내보내기.json` 내려받기
3. 서버 버전 → 선생님 로그인 → 기본정보 → 교사 모드 → **데이터 가져오기** → 파일 선택 → 미리보기 → 가져오기
- 가져오는 것: 학생(이름·직업·수학·자리), 잔액(이월 1줄), 국고 잔액, 신용 기록, 직업, 상점(남은 재고·이번 달 납부·오늘 구매 수), 이자율, 진행 중 예금, 진행 중 공동구매, 설정, 보드 글·댓글·추천
- 안 가져오는 것: 거래원장, 보드 사진, 비밀번호(모두 1111)

## 보드 사진
사진은 Firebase Storage(유료 플랜) 대신 Firestore에 줄인 JPEG(긴 변 1000px, 약 100~300KB)로 글과 따로 저장합니다. 무료 한도(저장 1GiB)로 수천 장까지 충분합니다. 설정에서 글당 사진 수·파일 수·댓글 수를 바꿀 수 있어요.

## 보드 파일 올리기
md·pdf·txt 파일을 글에 붙일 수 있어요(글쓰기 창의 "파일 고르기"). 사진처럼 Firestore에 글과 따로 저장해서 파일 하나는 700KB까지입니다. 글을 열면 파일 이름을 눌러 바로 보거나 "받기"로 내려받을 수 있어요. 큰 파일은 올릴 수 없어요.

## 보드 배치 두 가지
- **줄 맞춤**: 한 줄에 6칸 카드(기본). 선생님이 카드를 끌어 순서를 바꿔요.
- **자유 배치**: 넓은 판(3000×2200) 위에 카드가 놓여요. 카드를 옮길 수 있는 사람은 선생님뿐이고, 학생이 새 글을 쓰면 판의 빈 곳에 임의로 놓여요. 판은 마우스로 빈 곳을 끌어 옮기고(학생은 카드 위에서도), −/＋ 버튼, "전체 보기", Ctrl+휠, 두 손가락으로 확대·축소하고, 선생님은 "정리"로 카드를 가지런히 다시 놓을 수 있어요.
- 보드를 만들 때 배치를 고르고, 보드 관리에서 "자유 배치로 바꾸기/줄 맞춤으로 바꾸기"로 언제든 바꿀 수 있어요.

## 서버 읽기 줄이기 (Firestore 무료 한도 보호)
무료 요금제는 하루 읽기 5만 건이라, 같은 값을 반복해서 읽지 않게 해 두었어요.
- 학생 명단은 서버가 10분 기억해요 (등록·이름 고치기·가져오기 때 바로 새로 읽어요).
- 보드 글·댓글·추천은 45초, 보드 목록의 글 개수는 5분 기억해요. 그 보드에 글·댓글·추천이 생기면 바로 새로 읽어요.
- 추천·댓글·글쓰기·삭제는 화면에 먼저 반영하고 서버에는 저장만 보내요. 다른 사람이 올린 것은 보드를 나갔다가 다시 들어오면 보여요.
- 직업 활동·기타의 제출 체크와 과제 체크는 자동으로 새로 읽지 않아요. 다른 사람이 체크한 것은 “새로고침”을 눌러야 보여요.
- 선생님 화면 중 학생 관리·국고·직업 배정은 10초 기억하고, 무엇이든 저장하면 바로 비워요.
- 직업·설정은 1분 기억하고, 고치면 바로 비워요.
- 상점·은행·공동구매처럼 돈이 오가는 화면은 기억하지 않고 매번 새로 읽어요.

## 참고
- 이전 시제품에서 만든 학생·상품 데이터는 새 구조와 달라 화면에 나오지 않습니다 (필요하면 Firebase 콘솔에서 `students`, `items`, `meta` 컬렉션을 지우고 다시 등록하세요. 특히 `students`는 지우고 다시 등록하는 것을 권합니다).
- 학생 로그인은 번호+비밀번호 방식입니다. 한 번 로그인하면 그 기기에 60일간 저장되고, 서버가 잠들어 있거나 일시적으로 오류가 나도 저장된 로그인은 지워지지 않아요(서버를 깨우며 최대 1분쯤 다시 시도). 로그인이 정말 만료됐을 때만 다시 입력하면 돼요.
- 선생님은 비밀번호 대신 **구글 계정으로 자동 로그인**할 수 있어요 (아래 설정 필요). 선생님으로 들어가면 학생 미리보기 없이 시작하고, 기본정보의 교사 모드가 자동으로 열립니다. 위쪽 선택 칸에서 학생을 고르면 그 학생 화면을 미리 볼 수 있어요.

## 선생님 구글 자동 로그인 설정
1. [Google Cloud 콘솔](https://console.cloud.google.com/) → API 및 서비스 → 사용자 인증 정보 → **OAuth 클라이언트 ID 만들기** (유형: 웹 애플리케이션)
2. **승인된 자바스크립트 원본**에 서버 주소(예: `https://내서비스.onrender.com`)를 추가
3. Render 환경변수에 `GOOGLE_CLIENT_ID`(위에서 만든 클라이언트 ID)를 추가하고 다시 배포
4. 자동 로그인되는 계정은 `ddchani37@gmail.com`, `e.cg.b150@on.use.go.kr` 입니다. 바꾸려면 환경변수 `TEACHER_GOOGLE_EMAILS`에 쉼표로 구분해 넣으세요.
- 구글로 들어온 선생님은 로그인이 그 기기에 60일간 저장돼 닫았다 열어도 풀리지 않아요(비밀번호로 들어온 선생님은 예전처럼 12시간, 창을 닫으면 풀림). 공용 기기에서는 "나가기"를 꼭 눌러 주세요.
- 로그인 화면에 구글 버튼이 생기고, 이 기기에서 이미 위 계정으로 구글에 로그인돼 있으면 열자마자 선생님으로 들어가요. "나가기"를 누르면 바로 다시 자동 로그인되지는 않아요.
- `GOOGLE_CLIENT_ID`를 넣지 않으면 구글 버튼은 나오지 않고 기존 비밀번호 방식만 쓰여요.
- 기관(교육청) 계정은 관리자가 외부 앱 로그인을 막아 두었다면 구글 로그인이 안 될 수 있어요. 그땐 개인 계정으로 들어가세요.
- Render 무료 서버는 접속이 없으면 잠들어 첫 접속이 느립니다. `/ping`을 주기적으로 호출하면 완화됩니다.
