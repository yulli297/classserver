# 돼지공주나라 서버 버전 — 개발 기록

기존 Google Apps Script + Sheets 앱('돼지공주나라', 화폐 '행복', 24명 학급)을 **별도의 서버 버전**으로 옮기는 개발 기록이에요.
운영 중인 기존 앱은 건드리지 않았고, 2월 1일 데이터 삭제 시점에 맞춰 실제로 옮길 계획이에요.

## 1. 구성
- 서버: Node.js + Express (`server.js`), 화면: 한 장짜리 `public/index.html`
- 저장소: Firebase Firestore (사진은 Storage 대신 Firestore에 줄여서 저장 — 무료 유지)
- 배포: GitHub `yulli297/classserver` → Render (환경변수 `FIREBASE_SERVICE_ACCOUNT`, `TEACHER_PASSWORD`, `TOKEN_SECRET`)
- 로그인: 학생 번호 + 4자리 비밀번호(처음 1111, SHA-256 저장). 학생 토큰 60일(기기에 저장, "나가기"로 해제), 선생님 12시간(창 닫으면 해제)
- 돈 기록: 원장(`ledger`)에 한 줄씩 쌓고 `students.balance`는 합계 캐시, 국고(`treasury`)는 수입 +, 지출 −. 같은 번호의 거래는 두 번 들어가지 않음(멱등)
- 디자인: 토스 느낌 + 서류철에 붙은 포스트잇 탭, 탭을 누르면 종이가 넘어가는 효과. 교사 화면은 학생 화면과 같고, 배너마다 "교사 모드" 버튼으로 교사 기능이 학생 화면을 덮음
- 투자 기능은 이번 서버 버전에서 제외(나중에 직접 새로 만들 예정). 실시간 채팅도 제외

## 3. 지금 있는 기능
**기본정보** — 행복·신용등급·수학등급(스스로 입력)·월급·월세·내 자리, 최근 내역, 비밀번호 변경.
교사 모드: 승인, 학생 관리, 월급 지급, 행복·신용 조정, 학생 등록, 국고, 설정, 데이터 가져오기.

**은행** — 예금 1주·2주·1달(신용등급별 이자율, 중도해지는 원금만). 카드는 3줄 설명. 1달 이자율 15·13·11·7·5%.
**1주·2주 이자율은 임시값**(1주 3·2·2·1·1, 2주 4·3·2·1·1)이라 은행 교사 모드에서 조정 필요. 상품 추가·이름 고치기·없애기 가능.

**상점** — 세금(월세·전기세·건강보험료, 매달 16일에 새 납부 주기)·간식·쿠폰·공동구매. 자리를 산 학생은 월세 면제.
**직업소** — 직업 목록, 등급 조건, 정원, 교사 배정.

**직업 활동** — 내 직업의 "매일 할 일 / 주기적으로 할 일"(없으면 "없음"), 직업 권한별 도구:
- 경찰: 벌금 신청(지각 15행복, 욕설·기타는 금액 직접 입력) → 선생님 승인 후 부과
- 아르바이트생: 한 일 + 원하는 행복 입력 → 선생님 승인 후 수당 지급
- 국토교통부 장관: 자리 관리(칸별 가격·앉히기·징수 신청, 통로는 설정 `통로위치`)
- 통계청 공무원: 제출 체크(학생마다 O/X 버튼 즉시 반영, 몇 초마다 공유 새로고침, 기록 저장은 선생님)
- 국세청장: 국고 현황, 이번 세금 납부 현황, 국고 사용 신청
- 신용등급 평가원: 신용 현황·등급 기준 미리보기와 저장
- 성실 은행장·나눔 슈퍼: 은행·상점 교사 모드 기능

**우리반 보드** — 클릭하면 파스텔 노랑 전체 화면, 좌측 상단 "+" 버튼으로 글쓰기, 한 줄 6칸 padlet 카드(좁고 긴 카드, 카드를 누르면 크게 열려 댓글·추천). 사진 최대 5장(화면에서 자동으로 줄임). 선생님은 교사 모드 없이도 카드를 끌어서 순서를 바꿈. 보드 전체 삭제 기능.

**기타(선생님 전용 배너)** — 직업 변경·추가, 자리 확인(자리 배치 초기화 버튼), 과제 즉시 체크, 과제 만들기·관리.

**과제** — 상태는 진행중 → 검토대기 → 마감. 선생님이 기타 → 과제 만들기·관리에서 내면 학생 기본정보의 "오늘의 과제"에 나타나고(진행 중 최대 6개, 설정 `과제최대개수`), 학생은 "다했어요"를 누름. 통계청 공무원은 직업 활동의 "과제 체크"에서 과제를 눌러 학생별 O/X를 체크("다했어요 누른 친구 채우기" 가능)하고 "선생님께 보내기"를 누르면 학생 화면에서 사라지고 더 고칠 수 없음. 선생님은 "확인을 기다리는 과제"에서 확인·수정 후 "최종 저장하고 마감하기"(체크 안 한 친구는 제출 처리, 신용점수 반영) 또는 "통계청에 돌려보내기", 과제 삭제. 과제를 낼 때 "미제출하면 신용점수 감점"을 켤 수 있고(기본은 꺼짐, 감점 점수는 설정 `과제미제출감점`, 기본 1점), 과제를 연 뒤에도 마감 전까지 켜고 끌 수 있음. 통계청에는 즉시 체크(과제 없이 체크)를 제공하지 않고, 즉시 체크는 선생님 기타 배너에만 있음.

**승인** — 벌금·국고 지출·자리 징수·알바 수당을 한 곳에서 처리(체크한 벌금 한꺼번에 승인 가능).

## 4. 데이터 가져오기 순서
1. 기존 앱 Apps Script에 `tools/내보내기.gs` 최신 내용을 붙여넣고 `내보내기_서버버전` 실행 → JSON 파일 생성
2. 서버 앱 → 선생님 로그인 → 기본정보 → 교사 모드 → 데이터 가져오기 → 미리보기 확인 → 가져오기
3. 학생·잔액(이월 한 줄)·국고·직업·상점·이자율·자리·신용·예금·공동구매가 옮겨지고, 거래원장·보드는 옮기지 않음. 비밀번호는 모두 1111
4. 파일에 자리가 있으면 서버의 자리가 전부 파일 내용으로 바뀜. 자리가 없으면 경고가 뜸
5. 처음 시작 시 잘못 넣은 학생 데이터는 Firebase 콘솔에서 컬렉션(students, ledger, treasury, sales, credits, deposits, groupGoals, groupJoins, mathLog, boards 관련, items, meta)을 지운 뒤 다시 가져오기

## 5. 알아 둘 점 · 남은 일
- 실제 Firebase에서는 아직 전체 시험을 못 했고, 가짜 서버·브라우저 자동 테스트로만 확인함 → 배포 후 직접 확인 필요
- 1주·2주 이자율 임시값 조정
- 학생 비밀번호를 초기화해도 이미 로그인된 기기는 60일간 유지됨(필요하면 기존 로그인 끊기 기능 추가)
- 공용 기기는 "나가기"를 눌러야 다음 학생이 자기 계정으로 들어감
- 앱 안의 "전체 초기화" 버튼은 아직 없음(요청 시 추가)
- 보드 사진은 Firestore에 저장하므로 양이 많아지면 용량 점검 필요
- 기존 앱의 디자인은 한 학기 운영 후 개편 예정이고, 서버 버전은 사용하며 조정 예정
